# 第七章 結論與貢獻總結

> **本章導讀**：7.1 回顧核心宣稱與教訓性結論；7.2 貢獻總結。

## 7.1 結論

本論文設計、實作並評估了 **TieredVol**：一個以加權條帶化為核心的 Linux 核心異質
磁碟儲存系統（Device Mapper target）。針對「多顆性能差異巨大的磁碟並存」的現實
情境，TieredVol 以**權重化分配**取代等權條帶，以**確定性 O(1) 映射**保證正確性，
以**瓶頸模型與 auto_weight** 引導權重選擇，並以**權重借調、鏡像、重建、壞區、
寫入快取**在單一 target 內完成動態平衡與容錯。

實驗證實的核心宣稱（各項證據見第六章）：

1. **加權條帶正確且確定**：分布逐 byte 精確（多組權重計數器全對，6.2.1）、
   映射 O(1) 純算術無表無鎖、全程 `err=0`、8 G crc32c verify 0 mismatch（6.2.2）。
2. **瓶頸模型成立**：`min(soloᵢ × ΣW/wᵢ)` 在 1–4 碟、多組權重、排水態與冷態下
   命中 ±5% 內（權重匹配場景，6.3.1）；最純展示為排水態疊碟（6:1:1:1）的
   `D×9 ≈ 1760` 與 B@x4 四碟 [64:27:9:4] 的 `solo_A×104/64 ≈ 3354`
   （實測 3300、-1.6%）兩次命中；auto_weight 的 S4 偏差 -5.9% 與衰退複測
   -10.8% 屬枚舉顆粒度與硬體衰退之例外（6.3.2、6.3.3）。
3. **自動權重達近最優**：`auto_weight` 窮舉權重使寫入階梯嚴格單調
   （2078 < 2410 < 2896 < 3006）、模型上界達 Σsolo 的 99.6%（實測 93.7%）、
    S4 較等權重提升 70.6%（6.3.2）。
4. **共享匯流排需 DMI-aware 權重**：比例權重在三碟共用 PCH DMI 時掉到 2561 MB/s，
   DMI-aware 權重恢復至 3370 MB/s（+32%），並以 `solo_A + DMI` 數學上解釋了
    「三碟寫入不會超過兩碟」的硬體天花板；四碟 [64:27:9:4] 下 DMI 預算把瓶頸
   交還 A 碟、實測 3300 以 -1.6% 偏差命中（6.3.1、6.3.4）。
5. **可靠性機制整合**：鏡像、重建、壞區、權重借調（含持久化與 reload 恢復）、
   小寫入快取在單一 target 內運作，無引入額外錯誤（6.2、6.5）。

**教訓性結論**：異質碟條帶化的關鍵不在「權重正確」（那是確定性問題——任何權重
都能做到分布正確），而在**權重與實際速比的匹配**（那是性能問題）。權重失配即使
分布精確也會損失 36% 以上吞吐（6.3.3）；而「速比」本身又受 PCIe 插槽（3.7 倍，
6.3.5）與共享匯流排 DMI（封頂於 `solo_A + DMI`，6.3.4）影響——**效能工程必須在
真實拓撲上量測，否則模型與數據都會失真**。

## 7.2 貢獻總結

1. **加權條帶化 + 確定性無表 O(1) 映射**：純四則運算、逐 byte 精確、可重現、
   熱路徑無鎖（第三章 3.2）。
2. **瓶頸性能模型與 DMI-aware 權重分配**：`min(solo×ΣW/w)` 之證明與跨場景驗證；
   共享匯流排下的權重修正公式（3.3）。
3. **auto_weight 窮舉式自動權重工具**：由量測自動求近最優權重（近最優、+70.6%）。
4. **動態權重借調**：靜態佈局上的例外機制，持久化/reload 恢復（第四章 4.1）；
   宣稱以機制正確性為主，性能效益為條件性（6.5）。
5. **多機制單 target 整合**：鏡像、重建、壞區、併發一致性、寫入快取（4.2–4.5）。
6. **四層測試架構與真實平台剖析**：單元→核心模擬→dmsetup→fio；揭露插槽、
   DMI、SLC 三大硬體洞見（第五章 5.8、第六章 6.3）。
