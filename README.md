# TieredVol — Weighted Striping for Heterogeneous Disks

A Linux **Device Mapper** target implementing weighted striping across heterogeneous
disks: a deterministic O(1) table-less mapping, a bottleneck performance model,
dynamic weight borrowing, mirroring, and a small-write cache. This repository is the
master's thesis (National Yunlin University of Science and Technology, Dept. of
Computer Science and Information Engineering), authored in Markdown.

[中文版（正體中文）](README.zh.md)

## Build

Requirements: `pandoc`; for PDF also `xelatex` (TeX Live / MiKTeX) plus a CJK font.

**English is the default build language.** Append `zh` to build the Chinese version.

```bash
# HTML preview (SVG renders natively — recommended for checking layout)
scripts/build_pdf.ps1 html        # Windows PowerShell → English
scripts/build_pdf.ps1 html zh     # → Chinese
./scripts/build_pdf.sh html       # Linux

# DOCX (Word; figure references switched from SVG to PNG)
scripts/svg2png.ps1               # first: convert figs/*.svg to figs/*.png
scripts/build_pdf.ps1 docx        # → thesis_en.docx (English)
scripts/build_pdf.ps1 docx zh     # → thesis.docx (Chinese)

# PDF (LaTeX)
scripts/build_pdf.ps1             # English (run svg2png.ps1 first)
scripts/build_pdf.ps1 pdf zh      # Chinese

# PDF preview without TeX (headless Chrome)
scripts/build_pdf.ps1 chrome
```

## Website

The `website/` directory is a Vite + Vue 3 SPA (hash-router, en/zh). Content is
synced from `src/`, `src_en/`, `figs/`, and the driver repo:

```bash
node website/sync.mjs         # copies chapters + figures into website/src/content
cd website && npm run build   # production build (dist/)
```

Deployment is automated via GitHub Actions (`.github/workflows/deploy.yml`), which
also checks out `yu20060715/TieredVol-DRIVER` for the driver documentation.
