## 2. 論文宣稱（貢獻，5 項）

1. **加權條帶化 + 確定性無表映射**：異質碟依權重均分 I/O，映射為 O(1) 數學運算（非查表），分布可重現、逐 byte 精確、零誤差。
2. **瓶頸性能模型與自動權重**：總吞吐 `min(soloᵢ × ΣW / wᵢ)` 精確命中（±5% 內）；配合窮舉式 `auto_weight` 工具可達理論最優（Σsolo 99%+，比等權重 +52%）。
3. **動態權重借調（borrow table）**：以細粒度（1/28 KB 級）向快碟借額度填滿慢碟空檔，映射可持久化並於 reload 後恢復。
4. **多裝置管理與容錯**：鏡像、重建、壞區記錄（badmap/rebuild_badmap）、並發一致性（pending ring）、小寫入快取（WC）整合於單一 target。
5. **四層測試架構 + 真實異質平台剖析**：單元→核心模擬→dmsetup→fio 四層驗證；並揭露 PCIe 插槽（x1/x4）、PCH DMI 頻寬牆、SLC 暫態等硬體行為對儲存效能之影響。
